# Better SOLAR 1.0.9

The timetable uses consistent code/title and time/room font sizes instead of shrinking individual blocks. Course blocks across Dashboard, Schedule and Assessment and the visualizer open complete course information. The visualizer provides Remove selected course and Remove all courses alongside those fields. Offering credits are enriched from collected curriculum data where available; unavailable values are not guessed. The external-link restoration hint appears with Do not ask again.

Version 1.1.0 builds on these behaviors with a three-day mobile viewport, fixed hour rail, aligned course fields and compound checkbox layouts. See the newer change log for its mobile presentation changes.
